### 💻 What is INFINITY OS?
Real multitasking OS built for:
- **ASUS Vivobook & All Laptops** (Mouse + Keyboard)
- **Modio M36 & All Tablets** (Touch + Swipe)
- Works online & offline

### 🚀 Features - Real Working Apps
- 🌐 **Chrome Browser** - Real Google, Wikipedia, YouTube
- 💻 **Code Studio** - Live HTML/CSS/JS IDE + VS Code Web
- 📝 **Office 365** - Microsoft Office + Google Docs + Canva
- 🎬 **Media Center** - Play MP4, MP3, YouTube (supports Shorts, youtu.be)
- 🖼️ **Photo Editor** - B&W, Sepia filters
- 🎮 **Games** - Snake, TicTacToe, Flappy Bird
- ⌨️ **Linux Terminal** - Real commands: ls, help, neofetch
- 🛒 **App Store** - YouTube, Netflix, Spotify, Photopea, Figma, GitHub
